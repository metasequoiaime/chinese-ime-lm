# Agent Note: token 嵌入直接写入最终输入行

Status: proposed

## Problem

主项目固定 `5439b9675ca70a0ea4c3b7d51ec9f3d0420aca21`、完整锁定资源的默认 Runtime 九键十八秒采样，`linear_into` 和 `dot_i8` 分别有 1201 和 647 个栈顶样本，二元评分仍为另一主热点。采样从进程启动后三秒开始，含启动工作，不以其延迟作为成绩。源码另确认 `embed` 为每个 token 调用 `Matrix::row` 申请一行临时 Vec，再与位置相加到已经申请好的目标行，马上析构。此处工作量确定冗余，不据采样断言它是主要瓶颈。

## Proposal

在 `Matrix` 内直接将浮点或按行缩放的 int8 token 值与位置逐项相加，写入目标行。保持先乘 scale 再加位置的运算顺序、token 越界裁剪及 position 饱和行为。只保留整次嵌入的输出 Vec；不增缓存、unsafe、依赖、常驻权重展开或公开接口。

## Existing decisions

检索 embedding、token.row、嵌入、矩阵行与反量化。没有旧 embedding 决定。[末层上文单行](../../implemented/bug-fix/2026-10-17-prefix-final-row.md)部分重叠，继续约束实际查询位置；[临时权重行反量化](../../rejected/testing/2026-10-17-linear-temporary-row-dequant.md)只影响点积的跨位置共享，失败决定保留，本项不改变矩阵乘法。其余矩阵行分派、交错及投影 scratch 的拒绝记录与此申请无关。没有完全吸收或过时提案。

## Alternatives considered

- 返回借用的浮点行、量化行仍物化：能少改量化入口且消除 Float 申请，但当前分发模型 token 为量化，主要入口仍保留临时行。
- 跨调用持有 token 行工作区：可保留原两次循环，但增加工作区状态与一次复制；目标行已经存在，直接写入更简单。

## Acceptance criteria

先用完整冻结旧嵌入与当前生产入口跑相同 release 门槛，旧实现必须失败。宽 192/768、Float/Quantized、位置数 1/4/12/64 共 16 形状；每形状 21 对交替顺序，旧臂三次校准的最短值至少 5ms，包含输出和临时行申请析构，所有形状逐对 new/old 中位 <0.95。一次有效失败即拒绝，不放宽门槛或按结果挑形状。普通宽 1/7/8/9/192/768、空输入、超词表 token、偏移和上下文末端逐位对照，固定真实模型另验。完整旧新模型 bench 表、全测试、MSRV 1.75、Clippy、fmt；主项目固定接入另测逐键预算和完整质量。

## Risks

消除申请不等于整体模型或九键明显提速；计时单独运行并监测构建进程，系统负载不证明独占。旧行物化只保留在冻结测试中。模型数值不允许改变，常驻存储不增加。

## Measurement corrections

第一次红测试遗漏旧体的 `FORWARD_POSITIONS` 测试计数，独立只读审查指出后补齐；不将这轮作为完整入口的量化证据。补齐后另发现单次校准被调度停顿放大，192 Float 单位置仅迭代 64 次、正式批次约 6us，不能解释成每臂 5ms。因此在首次计量新版前改为三次校准最短值达 5ms，并重跑旧实现红测试。保留所有原始日志；门槛、形状和配对数保持。最终数据只使用修正后的同一工具定义。

旧版完整模型 bench 首次运行有 112 次监测，其中 1 次观察到外部 rustc，耗时 119.51 秒；该整表只作为受干扰观察保留，不据此宣称模型收益。系统一分钟负载一度超过 100，不可能通过仅检查编译进程证明机器独占。
