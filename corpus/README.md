# 语料

两个来源，两种用法。

| 路径 | 作用 |
|---|---|
| `fetch.py` | **获取**许可清晰、可再分发的语料（C4、LCCC，以及可选的维基与技术文档），流式下载并直接规范化 |
| `clean/` | **清洗**你自己准备好的语料：把非汉字一律当分隔符，切出纯汉字连通块 |
| `pinyin/` | 生成单字拼音表，供 n-gram 解码使用 |

两者的中文规范化是同一个算法。`fetch.py` 解决的是本仓库 README 提出的那个前置问题——发布模型之前，必须先把所用语料子集的许可定下来。

## 依赖

`clean/` 与 `pinyin/` 用根目录的 `requirements.txt`（`regex`、`opencc`）。`fetch.py` 只用标准库。
