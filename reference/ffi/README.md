# chinese-ime-lm-ffi

The C ABI for [`chinese-ime-lm`](https://crates.io/crates/chinese-ime-lm), a character-level language model that reranks the candidates a Chinese pinyin input method has already produced. It gives input methods written in C, C++, Swift, Kotlin (through JNI) or anything else with a C FFI the same model and the same gating as a Rust engine.

**It does not decode pinyin.** It takes the candidate list your engine assembled and judges which one the preceding text supports.

## Build

```sh
cargo build --release
```

This produces a static library (`libchinese_ime_lm_ffi.a`, or `chinese_ime_lm_ffi.lib` on Windows) and a shared library in `target/release/`. The header is [`include/chinese_ime_lm.h`](include/chinese_ime_lm.h); it is generated by cbindgen and committed, so reading or vendoring it needs no Rust tooling.

A static library needs a few system libraries linked alongside it, and they differ by platform. Ask rustc for them:

```sh
cargo rustc --release --lib -- --print native-static-libs
```

The minimum Rust version is 1.75, the same as `chinese-ime-lm`.

## Use

```c
#include "chinese_ime_lm.h"

// Once per process. The bytes are only read during the call.
cimelm_model *model = NULL;
if (cimelm_model_load(bytes, len, &model) != CIMELM_STATUS_OK) {
    fprintf(stderr, "%s\n", cimelm_last_error());
}

// Once per input session; it keeps the committed text's state across keystrokes.
cimelm_reranker *reranker = NULL;
cimelm_reranker_new(model, &reranker);

// On each keystroke, with the engine's candidates in its own order.
cimelm_str candidates[] = {{"西安", 6}, {"现", 3}};
uint8_t answers_key[] = {1, 1};           // both consume the whole key
uint8_t trusted_dictionary_hit[] = {0, 0};
size_t first = 0;
cimelm_reranker_best_where(reranker, (cimelm_str){context, context_len}, candidates, 2,
                           answers_key, trusted_dictionary_hit, &first);
// `first` is the candidate to show first; 0 keeps the engine's order.

cimelm_reranker_free(reranker);
cimelm_model_free(model);
```

Strings are UTF-8 with an explicit byte length and need no terminating NUL. A flag is true when it is non-zero.

`cimelm_reranker_best_where` applies the two gating rules the measurements require: it never overrides a dictionary hit you trust, and it only compares candidates that answer the whole key. The header documents both flags in full; read that before filling them in, because an engine that corrects input has to answer them differently from one that does not. `cimelm_reranker_log_probabilities` returns the raw per-character scores without the gating, for combining the model's opinion with evidence the engine already has.

### Threads

A model is read-only and may be shared by any number of rerankers on any number of threads. A reranker may move between threads but must not be used by two at once; create one per input session. Freeing a model does not invalidate the rerankers created from it.

### Errors

Every fallible call returns a `cimelm_status`. On anything but `CIMELM_STATUS_OK`, `cimelm_last_error()` describes the failure on the calling thread. Null or misaligned pointers, oversized lengths and invalid UTF-8 are reported as `CIMELM_STATUS_INVALID_ARGUMENT`, and a malformed model file as `CIMELM_STATUS_INVALID_MODEL`. A panic inside the library is caught rather than unwound into your process and reported as `CIMELM_STATUS_PANIC`; a reranker it happened in refuses every later call and has to be freed.

## Models

The weights are published on Hugging Face as [pinyin-ime-reranker-4M](https://huggingface.co/metasequoiaime/pinyin-ime-reranker-4M) and [pinyin-ime-reranker-25M](https://huggingface.co/metasequoiaime/pinyin-ime-reranker-25M). Take the 4M model for anything that runs on a keystroke. A downloaded model is untrusted input; [`SECURITY.md`](https://github.com/metasequoiaime/chinese-ime-lm/blob/main/SECURITY.md) describes how to check one before loading it.
